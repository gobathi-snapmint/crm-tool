Core Architectural Guarantees

1. Human-Only Launch: AI agents prepare drafts, validate compliance, and format specs. Launch authority remains 100% human.
2. India-Only Data Sovereignty: Bedrock India profiles route solely between Mumbai (ap-south-1) and Hyderabad (ap-south-2).
3. Zero PII in Prompts: Models only see product attributes and cohort aggregations—never individual customer names, phones, or credit data.
4. Deterministic Truth: All numbers, characters, and metrics are calculated by Python code and Databricks SQL—never estimated by the LLM.

Phase-by-Phase Engine Architecture

The 7 specialized modules delivering end-to-end campaign automation.

Phase 1: Content & Copywriting Agent

Claude Sonnet 5

Parses calendar briefs, queries Bedrock Knowledge Base for top-converting historical campaigns, and generates 3 copy variants across English, pure Hindi, and conversational Hinglish. Enforces strict character bounds and UTM tags.

Phase 2: Creative Rendering Engine (Deterministic HTML to PNG)

Headless Chromium (VPC)

Receives a structured Layout JSON from the Content Agent (headline, badge discount, partner logo ID, colors) and renders pixel-perfect PNG banners in <400ms inside our Mumbai VPC. Claude Sonnet 5 Vision verifies contrast and bounding boxes.

Phase 3: WhatsApp Approval Agent (Dual-Model Consensus)

Sonnet 5 + GPT-5.6 Terra

Protects Snapmint against Meta WABA account downgrades. Evaluates template classification independently across two model families. Both models must agree unanimously for a template to be marked as Utility; otherwise hard-locked to Marketing. Submits via Route Mobile / Infobip API.

Phase 4: SMS / DLT Compliance Engine (TRAI Mandate)

SHA-256 Text Hashing

Normalizes SMS text and compares SHA-256 hashes against approved Vilpower DLT templates. Calculates GSM-7 (160 chars) vs. UCS-2 (70 chars) split credits. If unregistered, outputs a One-Click Registration Package for manual submission.

Phase 5: WebEngage Draft Execution Package & Read-Back Diff

Deterministic Diff Engine

Assembles verified copy, creative URLs, UTM strings, and audience criteria into a guided side-by-side checklist. Reads back the WebEngage draft and performs automated text-diffing to catch copy-paste errors before launch.

Phase 6: Analytics & Databricks Lakehouse Feedback

Databricks SQL Warehouse

Pulls deterministic delivery, clicks, and 30-day BNPL conversion metrics via SQL queries. Analytics Agent generates executive WoW/MoM narratives. Top 10% campaigns automatically seeded into Content Library.

Phase 7: Calendar Planning & Capacity Optimization

Claude Opus 5

Combines frontier LLM reasoning with a deterministic constraint solver to schedule monthly campaigns, enforcing customer frequency caps (e.g. max 2 WhatsApps/week) and channel budget limits.
